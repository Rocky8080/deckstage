04 / OVERVIEW

四个能力，一条流水线

创作层
一屏一个 HTML tokens.css 配色 reveal 动效

放映层
全屏 总览 备注 画幅 16:9 · 4:3

交互与画幅自适应由引擎负责，配色主题随时整套切换。

导入导出层
PPTX → HTML 页内导出可编辑 PPTX 单机版 HTML

与 PowerPoint 双向流通；单机版断网也能放映。

管理层
/admin 追踪 deck 门禁 上下架

公开分享时的运营面：访问数据、密码门禁、即时上下架。

一条流水线

src-slides/*.html → build.mjs → decks/<slug>/ → serve_deck.py → library.html

四层共用同一条数据流：改源 → 拼装 → 起服务 → 点开放映。

系统已经跑起来了，从每天最常用的放映操作练起。

四层能力：创作是写 HTML 源文件；放映是引擎负责的浏览器体验；导入导出解决与 PowerPoint 的双向流通；管理后台面向公开分享时的运营。数据流一行：源文件拼装成单文件 deck，本地服务起展示台，浏览器点开即放映。

07 / AUTHORING

一屏 = 一个 HTML 文件

反例换主题就漏

标题写「概述」；颜色写死 #1E5B47；一屏塞 400 字正文。

名词标题立不住观点；配色主题整套失效；放映时溢出截断。

正例左边这屏的源码

<section class="slide" data-arch="contrast"
         data-title="…" data-rail="创作">
  <h1 class="title">一屏 =
    <em>一个 HTML 文件</em></h1>
  <div class="body"> … </div>
  <aside class="notes">演讲备注</aside>
</section>

data-rail 分章、data-title 进度条悬停可见、aside.notes 备注不占画面；颜色只用 tokens.css 变量。

所以规范就两条：标题是一句能被反驳的话，颜色只用变量。

写完跑 python3 tools/check_slides.py 自查溢出——下一屏看外部 PPTX 怎么进来。

创作模型：一屏一个文件放 slides 目录，类名体系见 docs/AUTHORING.md。正例面板就是本屏的真实源码（节选）。最关键的两条：高度预算不要超、颜色只用变量——其余规范都从这里推出来。

08 / IMPORT

外部 PPTX，一条流水线进展示台

  • 入口　展示台右上角「＋ 导入 PPTX」四步向导（体检 → 选项 → SSE 实时进度 → 入库）；CLI 同款能力：import_pptx.py，可先 --dry-run 只体检不动手

  • 保真与边界　每屏 = 原稿整页图 + 按 PDF 坐标补的可检索文字，视觉零偏差；导入 API 仅限本机（Host 守卫），改字要回源 PPTX 重导

6

个阶段全自动

体检 → 预修 → 渲染 → 补字 → 组装 → 入库

4

步 UI 向导

与 CLI 同一条流水线，进度实时可见

1600×900

逐页渲染分辨率

源分辨率固定，与设计坐标 1:1

口径：六阶段按 import_pptx.py 流水线计；单文件 ≤300MB、仅限本机。

导入是单向快照；日常更新走源码创作，也可以随时导出回 PPTX。

两条导入路径：UI 向导与 CLI。六阶段里最关键的是补字层——LibreOffice 漏画的文字按原坐标补回来，可检索可复制。注意导入 API 只在本机开放，公网隧道一律 403。 口径与折算（页上不展开，被问再答）：1600×900 为 LibreOffice 渲染的固定源分辨率，与设计坐标 1:1；六阶段 = 体检 → 预修 → 渲染 → 补字 → 组装 → 入库；渲染底图相当于每页一张 1:1 设计稿。

10 / ADMIN

管理后台：/admin 一站管理

访问追踪

谁看了什么、看了多久
逐屏停留热度、来源与访客数
最近 100 条明细

密码门禁

单套 deck 设访问密码
门禁页可配提示语
通过后 30 天免重输

上下架

一键下架：整目录 404
展示台卡片即时消失
无需重新构建

安全边界

导入 API 仅限本机
管理 / 追踪接口有限流
数据在 data/ 不入库

  • 入口：展示台页脚「管理后台」或直接访问 /admin/；首次启动打印初始密码，--admin-password 可重置

  • 追踪只存随机访客号与可见时长，无个人身份信息；详见 docs/ADMIN.md

最后，把文档索引留给你。

管理后台四块：访问追踪（内容与时长的逐屏统计）、密码门禁、上下架、安全边界。首次启动会打印一次初始管理密码，之后可在面板里改。追踪数据匿名，只记随机访客号。

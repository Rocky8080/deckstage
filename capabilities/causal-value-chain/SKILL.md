# 因果链 / 价值链写作与审查

> **先说明比较口径，再交代按原方法完成同一任务所需的投入。**

## 1. 什么时候用

- 要把"我做了 X"写成有说服力的汇报页
- 手里有一堆数字，但听众记不住、也不信
- 有对照表，但看不出所以然
- 图很多，但图跟结论没关系

## 2. 方法骨架

### 2.1 因果链（Why it works）—— 五段

| 段 | 要回答 | 信息不足的写法 | 示例（假设的月报流程） |
|---|---|---|---|
| 现状 | 原本怎么做、成本多少 | “团队 4 人” | 手工处理同一批月报需要 4 人 × 6 个月 = **24 人月** |
| 机制 | 哪些动作改变了成本 | “用了自动化” | 脚本汇总数据，团队审核异常记录 |
| 结果 | 同一把尺子量出的数字 | “只花了半年” | 处理同一批月报并沿用审核标准，投入 2 人 × 6 个月 = **12 人月** |
| 反事实 | 沿用旧做法需要多少资源 | （缺失） | 旧做法需多投入 **12 人月**，约等于多用 2 人工作 6 个月 |
| 结论 | 一句话，能被反驳 | “效率提升” | 在交付范围和审核标准相同的情况下，自动汇总使投入从 24 人月降至 12 人月 |

### 2.2 价值链（What it is worth）—— 四段

```
投入 ──→ 转化 ──→ 产出 ──→ 价值
(人月/时间/费用)  (能力/系统)  (可交付物)  (省下的未来时间 / 可复用性 / 溢价)
```

折算规则（全篇只用一把尺子）：

| 原始量 | 折算 | 公式 |
|---|---|---|
| 人数 × 月数 | 人月 | `人月 = 人数 × 月数` |
| 人月 | 年 | `年 = 人月 ÷ 12`（用于单人反事实） |
| 工作量 ÷ 人月 | 倍 | 必须写口径：人月 / 日历 / 费用 |
| tokens | 体感类比 | 只做类比，不做结论 |

### 2.3 数字三件套

**口径 · 基准 · 结论**，缺一条就只是原料。

- 口径：人数 × 投入的全职月数。
- 基准：同一批月报，采用旧的人工汇总流程和相同的审核标准。
- 结论：该假设示例的投入由 24 人月降至 12 人月。

### 2.4 图文因果链

**断言 → 指认锚点 → 可自证的结论**

| 图注类型 | 不合格 | 合格 |
|---|---|---|
| 写法 | “月报汇总流程” | “看右侧的异常清单，原始记录编号支持逐条复查。” |

图的三种角色：**证据**（可被第三方核对的痕迹）、**机制**（流程/分工）、**语境**（交代是什么）。
一屏最多一张证据图；全是语境图 = 截图墙。

## 3. 五条禁则

1. 不写没有比较对象的倍数
2. 不把不同量纲并列（人 / 月 / 次 / 页）
3. 表格没有"所以"那一行就不该出现
4. 结论不许"我觉得 / 应该是 / 大幅 / 显著"
5. 估算必须当场标口径，且能被追问复算

（引号内被讨论、被否定的说法不算违规。）

### 3.1 口径与补充说明放备注，页面只留主证据

放映时观众只该看到主证据与结论；口径、基准、折算、估算细节、题外解释
一律写进**当页备注**（`<aside class="notes">`），措辞用「口径与折算（页上
不展开，被问再答）：…」。页面上允许的例外只有一句话级的 `.source` 槽位；
超过一句就下沉。备注也是讲稿——里面的倍数同样要带基准词（如「相当于」）。
`frame.py audit` 会查出「口径上屏」与「备注倍数无基准」。

## 4. 自检 10 问

见 `python3 tools/frame.py checklist`。

## 5. 工具（可直接被 Codex / ZCode / DSH 调用）

```bash
python3 tools/frame.py framework                 # 打印方法骨架，可拼进 prompt
python3 tools/frame.py checklist                 # 10 问清单
python3 tools/frame.py audit <文件|glob>          # 审查幻灯片/文档，输出问题表
python3 tools/frame.py audit <...> --json        # 机器可读（便于 agent 解析）
python3 tools/frame.py lint "<一段话>"            # 单句/单段禁用表达检查，有问题退出码 1
```

规则覆盖：无基准倍数、表格无结论、量纲未统一（N 人 + N 个月却没人月）、图无指认锚点、图注描述式、缺反事实、禁用表达、缺结论、口径上屏（补充说明应移入当页备注）、备注倍数无基准（P2 提示）。备注（aside.notes）不计入页面级检查——它是讲稿，不是页面。

## 6. 输出模板（改完一屏照这个交付）

```
结论：<一句可被反驳的话>
因果链：现状（成本）→ 机制（可复述的动作）→ 结果（同一把尺子）→ 反事实（相当于 X 年）
价值链：投入 X 人月 → 转化（能力）→ 产出（可交付物）→ 价值（省下的时间/可复用性）
口径与基准：<数字的分子分母、和谁比>
图与锚点：<哪张图、看哪里、证明什么>
```

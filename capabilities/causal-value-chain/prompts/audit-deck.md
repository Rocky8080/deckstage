# 提示词：审查一份 PPT / 文档的表达

你可以直接复制下面这段给 Codex / ZCode / DSH（把 `<路径>` 换成实际文件或目录）：

---

请用「因果链 + 价值链」框架审查 `<路径>` 里的每一屏/每一节，并按严重度排序输出。

步骤：
1. 先运行 `python3 tools/frame.py audit "<路径>" --json`，拿到规则级问题（无基准倍数、表格无结论、量纲未统一、图无锚点、缺反事实、禁用表达、缺结论）。
2. 对每一屏回答：
   - 这一屏想让人记住的一句话是什么？页面上有吗？
   - 每个数字的口径 / 基准 / 结论分别是什么？缺哪个？
   - 有没有把人数、月数、次数、页数混着比？能不能折成同一把尺子（人月 / 倍 / 天）？
   - 有没有反事实（不这么做会怎样）？
   - 结论句能否被反驳？
   - 图文：遮住文字图能证明什么？遮住图句子还成立吗？图注是否写了"看这里"？
3. 输出表格：`屏 | 现在的说法 | 缺什么 | 建议改法（给可直接粘贴的文案）| 优先级 P0/P1/P2`。
4. 不要编造数字；缺数据就写"需要你提供：<具体是哪个数>"。

约束：
- 不要写没有比较对象的倍数；不要用"大幅/显著/翻倍"。
- 结论必须是一句能被复述、能被反驳的话。
- 表格如果保留，必须带一行"所以"；否则建议换成一条倍数或曲线。

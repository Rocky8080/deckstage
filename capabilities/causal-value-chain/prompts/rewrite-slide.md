# 提示词：把一屏"罗列"改成"结论"

---

把下面这一屏从「罗列素材」改成「有结论的表达」。

原文（或 HTML）：
<粘贴>

要求：
1. 先写结论句（一句，能被反驳）：
2. 补因果链五段：现状（成本）→ 机制（可复述的动作）→ 结果（同一把尺子）→ 反事实（相当于 X 年/倍）→ 结论
3. 所有数字折成统一货币（人月 / 倍 / 天），并标口径与基准
4. 如果原屏是对照表：把它换成一个主倍数 + 一条反事实；表格最多保留为脚注
5. 如果屏上有图：给每张图加"看这里"的锚点，并把图注从"是什么"改成"证明了什么"
6. 输出：① 新文案（可直接粘贴） ② 一句话说明"这屏现在证明了什么" ③ 仍缺的数据清单

不要编造数字；缺失的数请标 `【需补：xxx】`。

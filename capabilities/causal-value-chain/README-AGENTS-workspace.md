# 工作区写作约定

## 内容写作：因果链 / 价值链

写或改 **PPT、汇报、复盘、方案、对比表** 时，默认套用下面这套规则（不需要用户点名，也不依赖 skill）：

1. **数字三件套**：口径 · 基准 · 结论，缺一条就只是原料。
2. **一把尺子**：人月 = 人数 × 月数；人月 ÷ 12 = 年；倍数必须写口径（人月/日历/费用）。
3. **反事实**：出现倍数就要换算（"相当于 X 年 / 多花 X 人月"）。
4. **表格必须有"所以"**；能换成一个倍数或一条曲线就换掉。
5. **结论可反驳**：禁用「我觉得 / 应该是 / 大幅 / 显著 / 效率翻倍」（引号内被否定的除外）。
6. **图文因果链**：图注写"证明了什么"+"看这里"，不是"这是什么"。
7. 缺数据写 `【需补：xxx】`，不编数字。

# 用户级约定（本机所有 AI 客户端自动加载：DSH / Codex / ZCode / WorkBuddy / Claude Code）

## 写 PPT / 汇报 / 复盘时的表达纪律

只要在写或改「幻灯片、汇报、复盘、方案、对比表」，就按下面这套来，**不需要用户要求、也不依赖任何 skill 加载**。

### 数字三件套
每个数字都要有：**口径**（分子分母/时间窗/来源）、**基准**（和谁比）、**结论**（所以呢）。
缺任何一条，就还只是素材。

### 一把尺子
- 人月 = 人数 × 月数；人月 ÷ 12 = 年
- 倍数必须写口径（人月 / 日历 / 费用）
- 不把人数、月数、次数、页数混着比
- 出现倍数就要给反事实（"相当于 9.5 年"这种）

### 结论可反驳
结论句不许「我觉得 / 应该是 / 大幅 / 显著 / 效率翻倍」；表格没有"所以"那一行就不要放进正式页。

### 图文因果链
图注写"证明了什么"+"看这里"（具体数字/位置/颜色），不是"这是什么"。
一屏最多一张证据图，其余是机制图或语境图。

### 有工具就用工具
- 本仓库有 `tools/frame.py` 时：`python3 tools/frame.py audit <路径>` / `lint "<句子>"`，P0 必须为 0
- 本仓库有 `node build.mjs` 时：构建自带写作门禁，P0 会直接失败——不要用 `--no-frame` 绕
- 缺数据就写 `【需补：xxx】`，不要编数字

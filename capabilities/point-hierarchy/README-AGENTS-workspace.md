# 工作区约定 · 观点层级

## 结构：一页一断言、模块认领、页间接力

写或改 **PPT、汇报、复盘、方案** 时，先定观点再排内容（不需要用户点名，也不依赖 skill）：

1. **一页一断言**：标题是一句能被反驳的话，不是名词；一页只讲一个观点。
2. **模块认领**：每块内容指认它支撑标题里的哪个词；指不出来 → 删或移页。
3. **重复必合并**：同页高度重复合成一块；相邻两页讲同一件事合成一页或降成一句。
4. **接得住上一页**：承接（共用实词）/ 转折（但·不够·还差）/ 过渡句，三者有其一；都没有就是断链。
5. **一页别放太多**：论据 ≤ 3 块、每块 1 句 + 1 证据、可见字数 ≤ 520；细节写进讲稿。
6. **并列要分类 + 主次**：不同侧面加分类标签、不硬合并；同一观点只留一个「主」。
7. **每章有结论页**：每个章节至少一页承担「结果 / 结论」；没有结果就明说。
8. **交付观点地图**：L0 主张 → L1 章节结论 → L2 页面断言 → L3 模块（主 / 次 + 证据）。


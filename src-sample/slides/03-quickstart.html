02 / QUICKSTART

五分钟，跑通全流程

git clone … && cd deckstage
pip install -r requirements.txt          # python 工具链（PIL / fitz / numpy / python-pptx / playwright）

node build.mjs --src src-sample --deck sample-deck   # 拼装示例 deck
python3 tools/build_library.py                       # 展示台聚合 + 缩略图
python3 tools/serve_deck.py                          # http://127.0.0.1:8899/  ← 展示台

python3 tools/import_pptx.py 你的.pptx --slug my-deck --dry-run   # 只体检不动手
python3 tools/import_pptx.py 你的.pptx --slug my-deck             # 正式导入（UI 入口在展示台右上角）

依赖分两档：纯创作与放映零依赖，浏览器打开即可；PPTX 导入需要 LibreOffice，缩略图 / QA 需要 Chrome（Playwright 走 channel="chrome"）。

服务起来后，先鸟瞰这套系统的四层能力。

五分钟上手：装 python 依赖，拼装示例 deck，聚合展示台，起本地服务。导入是可选项，需要 LibreOffice。日常创作时只跑 build.mjs 就够，刷新浏览器即见。

外部 PPTX，一条流水线进展示台

  • 入口　展示台右上角「＋ 导入 PPTX」四步向导（体检 → 选项 → SSE 实时进度 → 入库）；CLI 同款能力：import_pptx.py

  • 流程　体检 → 版式预修（禁折行 / 缩字）→ LibreOffice 渲染 → 补字层 → 组装入库

  • 保真　每屏 = 原稿整页图 + 按 PDF 坐标补的可检索文字，视觉零偏差

  • 边界　导入 API 仅限本机（Host 守卫），单文件 ≤ 300MB；改字要回源 PPTX 重导

6个阶段全自动
4步 UI 向导
1600×900逐页渲染分辨率
300MB上传体积上限

导入是单向快照；日常更新走源码创作，也可以随时导出回 PPTX。

两条导入路径：UI 向导与 CLI。六阶段里最关键的是补字层——LibreOffice 漏画的文字按原坐标补回来，可检索可复制。注意导入 API 只在本机开放，公网隧道一律 403。

<section class="slide" id="s07"
         data-title="创作规范"
         data-rail="创作">
  <header class="head">
    <p class="kicker">06 / AUTHORING</p>
    <h1 class="title">一屏 =
      <em>一个 HTML 文件</em></h1>
  </header>
  <div class="body"> … </div>
  <aside class="notes">演讲备注</aside>
</section>

  • data-rail 决定顶部导轨分章；data-title 进度条悬停可见

  • reveal + --d 控制逐步入场；data-count 数字滚动；.frag 空格分步

  • aside.notes 是演讲备注，按 N 呼出，不占画面

  • 颜色只用 tokens.css 变量、不写死——配色主题才能整套生效

  • 写完跑 python3 tools/check_slides.py 自查溢出与截断

创作模型：一屏一个文件放 src-slides 目录，类名体系见 docs/AUTHORING.md。左侧深色卡片就是本屏的真实源码。最关键的两条：高度预算不要超、颜色只用变量。

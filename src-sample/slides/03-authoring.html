02 / AUTHORING

一屏 = 一个 HTML 文件

src-sample/slides/02-pipeline.html

<section class="slide" id="s02"
         data-title="六阶段导入 pipeline"
         data-rail="概览">
  <header class="head">
    <p class="kicker">01 / PIPELINE</p>
    <h1 class="title">外部 PPTX，
      <em>一条流水线</em>进展示台</h1>
  </header>
  <div class="body"> … </div>
  <aside class="notes">演讲备注</aside>
</section>

  • data-rail 决定顶部导轨分章；data-title 进度条悬停可见

  • reveal + --d 控制逐步入场；data-count 数字滚动

  • aside.notes 是演讲者备注，按 N 呼出，不占画面

  • 屏内可带 <style>，构建时自动提取合并进 head

这一屏讲创作模型：一屏一个文件，类名体系见 docs/AUTHORING.md。左侧深色卡片里就是上一屏的真实源码。

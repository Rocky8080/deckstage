03 / QUICKSTART

五分钟，跑通全流程

01

装依赖

git clone … && cd deckstage
pip install -r requirements.txt

产出：仓库与工具链就绪

02

拼示例

node build.mjs --src src-sample --deck sample-deck

产出：decks/sample-deck/

03

起服务

python3 tools/serve_deck.py

产出：127.0.0.1:8899 展示台

04

日常改

改 slides/*.html，重跑 build.mjs

产出：刷新浏览器即放映

依赖两档：创作与放映零依赖，浏览器打开即可；PPTX 导入需要 LibreOffice，缩略图 / QA 需要 Chrome（Playwright 走 channel="chrome"）。

服务起来后，先鸟瞰这套系统的四层能力。

五分钟上手：装 python 依赖，拼装示例 deck，起本地服务。导入是可选项，需要 LibreOffice。日常创作只跑 build.mjs 就够，刷新浏览器即见。

01 / INSTALL

安装，就是发一个链接

把仓库地址发给任意 AI 客户端（WorkBuddy / ZCode / DeepSeek Harness / Codex），下载、装依赖、起服务全自动。

WorkBuddy — 会话
帮我装一套 DeckStage：https://github.com/Rocky8080/deckstage
克隆到本地、装好依赖、把展示台跑起来。浏览器能打开就算完成。
git clone https://github.com/Rocky8080/deckstage && cd deckstage
pip install -r requirements.txt
python3 tools/serve_deck.py 展示台已启动 → http://127.0.0.1:8899/ 12 屏《使用说明》就在首页第一张卡片。

等效手动命令（愿意自己敲的话）

git clone https://github.com/Rocky8080/deckstage
cd deckstage
pip install -r requirements.txt

python3 tools/serve_deck.py
# → http://127.0.0.1:8899/

  • 客户端不限：WorkBuddy / ZCode / DeepSeek Harness / Codex 都行

  • 服务只监听本机 127.0.0.1；公开分享经隧道 + 管理后台门禁

  • 纯创作与放映零依赖；PPTX 导入另需 LibreOffice（AI 会提示）

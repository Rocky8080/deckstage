01 / PIPELINE

外部 PPTX，一条流水线进展示台

  • 体检　字体清单 / 画幅 / 语言判定 / 表格·组合统计 —— 只读不改

  • 版式预修　短行禁折 + 全局缩字 + 表格缩字，配方在真实 deck 上验证过

  • 渲染　LibreOffice 无头渲染 → 逐页 1600×900 位图，视觉与原稿一致

  • 补字层　检测没画出来 / 缺字方块的文字，按 PDF 坐标补成可检索的 HTML

  • 组装入库　生成 deck 源码目录 → 拼装 → 刷新展示台缩略图

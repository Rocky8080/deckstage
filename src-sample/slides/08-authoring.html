07 / AUTHORING

一屏 = 一个 HTML 文件

反例换主题就漏

标题写「概述」；颜色写死 #1E5B47；一屏塞 400 字正文。

名词标题立不住观点；配色主题整套失效；放映时溢出截断。

正例左边这屏的源码

<section class="slide" data-arch="contrast"
         data-title="…" data-rail="创作">
  <h1 class="title">一屏 =
    <em>一个 HTML 文件</em></h1>
  <div class="body"> … </div>
  <aside class="notes">演讲备注</aside>
</section>

data-rail 分章、data-title 进度条悬停可见、aside.notes 备注不占画面；颜色只用 tokens.css 变量。

所以规范就两条：标题是一句能被反驳的话，颜色只用变量。

写完跑 python3 tools/check_slides.py 自查溢出——下一屏看外部 PPTX 怎么进来。

创作模型：一屏一个文件放 slides 目录，类名体系见 docs/AUTHORING.md。正例面板就是本屏的真实源码（节选）。最关键的两条：高度预算不要超、颜色只用变量——其余规范都从这里推出来。

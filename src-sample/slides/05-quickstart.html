04 / QUICKSTART

五分钟，跑通全流程

git clone … && cd deckstage
pip install -r requirements.txt          # python 工具链（PIL / fitz / numpy / python-pptx / playwright）

node build.mjs --src src-sample --deck sample-deck   # 拼装示例 deck
python3 tools/build_library.py                       # 展示台 + 缩略图
python3 tools/serve_deck.py                          # http://127.0.0.1:8899/  ← 展示台

python3 tools/import_pptx.py 你的.pptx --slug my-deck --dry-run   # 体检一个外部 PPTX
python3 tools/import_pptx.py 你的.pptx --slug my-deck             # 正式导入（UI 入口在展示台右上角）

需要本机装有 LibreOffice（PPTX 导入用）与 Chrome（缩略图 / QA 用）；纯创作与放映则零依赖，浏览器打开即可。

依赖分两档：放映与创作零依赖；导入 pipeline 需要 LibreOffice + python 工具链。

04 / OVERVIEW

四个能力，一条流水线

创作层
一屏一个 HTML tokens.css 配色 reveal 动效

源文件即真源：改 HTML 重跑 build，浏览器外无构建。

放映层
全屏 总览 备注 画幅 16:9 · 4:3

交互与画幅自适应由引擎负责，配色主题随时整套切换。

导入导出层
PPTX → HTML 页内导出可编辑 PPTX 单机版 HTML

与 PowerPoint 双向流通；单机版断网也能放映。

管理层
/admin 追踪 deck 门禁 上下架

公开分享时的运营面：访问数据、密码门禁、即时上下架。

一条流水线

src-slides/*.html → build.mjs → decks/<slug>/ → serve_deck.py → library.html

四层共用同一条数据流：改源 → 拼装 → 起服务 → 点开放映。

系统已经跑起来了，从每天最常用的放映操作练起。

四层能力：创作是写 HTML 源文件；放映是引擎负责的浏览器体验；导入导出解决与 PowerPoint 的双向流通；管理后台面向公开分享时的运营。数据流一行：源文件拼装成单文件 deck，本地服务起展示台，浏览器点开即放映。
